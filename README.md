# 访谈文本主题编码工具

`sologsb-1019` 是一个面向质性研究者的本地优先主题编码工作台，使用 SolidJS、TypeScript 和 SUID 从零构建。

## 功能

- 导入带时间码或普通段落形式的访谈转写，自动切分片段。
- 创建任意层级主题树，维护操作定义、备忘录和典型示例。
- 为每个片段分别记录两位编码者的主题判断，并高亮分歧。
- 批量选择片段后重新编码，支持主题合并和按片段拆分。
- 从主题引用快速回到原文，并保留主题级与片段级研究记录。
- 完整撤销重做、操作审计、JSON 完整备份和 CSV 编码结果导出。
- 离线编码包下发与合并：按**访谈来源 + 原文指纹**对齐片段、按**主题路径**对齐主题，再做三方判断合并；只有同一位编码员改动同一项且内容不同才暂停等研究者裁决。旧数据包缺指纹/基线时先出迁移与复核清单；提交前写检查点，写入失败可在重开后继续应用或整包撤回。
- J/K、数字键、Alt+A/Alt+B、搜索与通用撤销快捷键。
- 使用 IndexedDB 和 localStorage 双写保存；刷新或断网后继续工作。
- 使用 BroadcastChannel 监测其他标签页修订，发生并发写入时显示冲突，不会静默覆盖。

## 技术栈

- SolidJS 1.9
- TypeScript 5.9
- SUID Material `@suid/material`
- Vite 7
- IndexedDB / localStorage / BroadcastChannel

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Vite 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1019 .
docker run --rm -p 10019:80 sologsb-1019
```

容器内由 nginx 监听 `80`，宿主端口 `10019` 仅由根项目端口表或部署命令映射。

## 数据说明

数据保存在浏览器本机，不会发送到远端。多个标签页同时编辑时后写入者不会自动覆盖先写入者；界面会要求研究者明确选择“载入其他标签页版本”或“保留本页并建立新修订”。

## 离线编码包合并流程

1. 在主机用顶栏「合并编码包 → 下载离线编码包」为某位编码员（A 或 B）生成 `.json`，包含全量快照、原文指纹、访谈来源键与下发基线。
2. 编码员在另一台机器用同一工具打开该包离线编码，带回更新后的包。
3. 在主机「合并编码包」选择带回的文件，系统先预演：
   - 片段按「访谈来源（来源文件/标题派生键）+ 归一化原文指纹」对齐，主题按「根 → 叶名称路径」对齐，因此两端编号不同也不会产生重复主题或把同一段当成两处修改。
   - 仅并入该编码员那一列判断，另一编码员列绝不触碰；A、B 两位同时改同一段不算冲突。
   - 只有「同一位编码员改动同一项且内容不同」才生成待裁决冲突，提交按钮在全部裁决前禁用。
   - 旧数据包缺原文指纹或基线时，先列迁移清单并按保守方式（并集 / 保留本地）预合并，逐条确认后才提交；无法确认的片段标记“未对齐”并阻塞，不会静默建重复。
4. 提交时先把「合并前快照 + 合并后状态 + 计划 + 包」原子写入 IndexedDB 检查点，再改写本地库。若落盘失败或中途关闭，重开页面顶部出现横幅，可「继续应用」或「撤回整包」恢复。

合并引擎为纯函数（`src/merge/engine.ts`），可用 `node scripts/merge-test.mjs` 运行断言自测。
